# WindowsHello

A modern, fast, FaceID-style face-unlock application for Windows, crafted by **Nikhil**. 

> **Disclaimer:** This app is designed for convenience and visual aesthetics. For deep system-level protection, always use a Windows password/PIN and BitLocker.

## Features
- **Face Recognition:** Unlock your screen simply by looking at the camera.
- **Customizable UI:** Choose your favorite vibrant gradients and styles, matching a brutalist design approach.
- **Offline First:** All face data is processed and stored locally on your device. No cloud uploads.
- **Safe Fallback:** Password protection and a custom exit shortcut ensure you are never locked out.
- **Smooth Animations:** Multiple scanning animation styles (Island, Wide, Bubble, Mesh, Glow) for a better experience.

## Installation
1. Download `WindowsHello Setup 1.0.0.exe` from the **Releases** page.
2. If Windows shows "Windows protected your PC", click **More info -> Run anyway** (the app is safe, but not currently code-signed).
3. Open the app to access the **Control Panel**.
4. Set a strong backup password, click **Enroll face**, choose a secret **exit shortcut**, and press **Test lock**.

## 💡 Important Notes
- Write down your **exit shortcut** somewhere safe! It is your ultimate backup to unlock the screen.
- The app requires Windows 10/11 (64-bit) and a working webcam.
- To prevent overlap with other apps, make sure you have adequate lighting during face enrollment.
