## ✨ Features

- **Face Recognition:** Unlock your screen simply by looking at the camera.
- ** Offline First:** All face data is processed and stored locally on your device. Zero cloud uploads.
- ** Safe Fallback:** Password protection and a custom exit shortcut ensure you are never permanently locked out.
- ** Smooth Animations:** Multiple scanning animation styles (*Island, Wide, Bubble, Mesh, Glow*) for a seamless experience.

---

## Installation

1. Download the latest `WindowsHello Setup.exe` from the [**Releases**](https://github.com/yadavnikhil03/WindowsHello/releases) page.
2. If Windows SmartScreen shows "Windows protected your PC", click **More info -> Run anyway** *(The app is safe, but not currently code-signed)*.
3. Open the app to access the **Control Panel**.
4. Set a strong backup password, click **Enroll face**, choose a secret **exit shortcut**, and press **Test lock**.

---

## 💡Important Notes

- **Backup Shortcut:** Write down your **exit shortcut** somewhere safe! It is your ultimate backup to unlock the screen.
- **Requirements:** Requires Windows 10/11 (64-bit) and a working webcam.
- **Lighting:** To prevent overlap with other apps, make sure you have adequate lighting during face enrollment.
